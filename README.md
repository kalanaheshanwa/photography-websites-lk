# Photography Websites by Kalana Square

A minimal, modern landing website for a managed website subscription created for Sri Lankan photographers.

## Current offer

- Essential — LKR 5,000/month
- Signature — LKR 8,500/month
- Studio — LKR 12,500/month
- Mobile-first portfolio presentation
- WhatsApp-focused enquiries
- Hosting, maintenance, and monthly content updates

## Development

Requires Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

The main page is in `app/page.tsx` and its styling is in `app/globals.css`.

## Production build

```bash
npm run build
```
